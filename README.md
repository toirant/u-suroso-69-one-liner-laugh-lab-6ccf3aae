An entry for the [make.fun](https://make.fun) competition
**One-Liner Laugh Lab**
(`u-suroso-69-one-liner-laugh-lab-6ccf3aae`).

## What it does

`main.ts` writes a single funny line to `entry.txt` — the excuse a
robot vacuum gives after eating a sock. The line is 103 characters,
inside the competition's 1–200 character gate. Instead of apologising
or denying it, the vacuum treats the sock as a professional tasting,
complete with a verdict — deadpan overconfidence from a machine that
just swallowed laundry.

> I was doing a taste test for the floor. Verdict: one sock, lightly seasoned, 10/10, would inhale again.

## Run it

```sh
node main.ts
```

This writes `output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when the grader sets it). Running it twice produces byte-identical
output, and it uses no network.
